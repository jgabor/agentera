Agentera gives coding agents shared project artifacts, behavioral verification
gates, and portable saved context across OpenCode, Codex, Cursor, and GitHub
Copilot.

Run `/agentera` (`$agentera` in Codex) and get a project briefing that reads
your repo instead of guessing from chat history.

## What makes Agentera different

| Approach        | Coordination model                                                     | State location               | Runtime portability                                   |
| --------------- | ---------------------------------------------------------------------- | ---------------------------- | ----------------------------------------------------- |
| Prompt chains   | Sequential prompts                                                     | Chat transcript              | Low                                                   |
| Agent platforms | Platform-owned workflows                                               | Vendor service               | Platform-bound                                        |
| Vector memory   | Retrieved snippets                                                     | External index               | Depends on integration                                |
| Agentera        | Capability-owned artifacts with behavioral acceptance and health gates | Your repo and data directory | OpenCode, Codex, Cursor, GitHub Copilot |

Runtime lifecycle state comes from one four-runtime authority. Cursor Agent CLI
and Cursor IDE are two surfaces of the single Cursor identity. `prime` returns a
bounded summary; `doctor` returns detailed evidence and manual actions.
