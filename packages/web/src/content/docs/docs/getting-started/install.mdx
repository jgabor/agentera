---
title: Install and lifecycle
description: Install Agentera and inspect lifecycle state on OpenCode, Codex, Cursor, or GitHub Copilot.
---

Agentera 3.0 uses one canonical portable skill and one lifecycle authority for
four active runtime identities: OpenCode, Codex, Cursor, and GitHub Copilot.

Before the stable npm dist-tag promotion, use `agentera@next` for CLI commands.

## Canonical skill

The canonical skill path is:

```text
~/.agents/skills/agentera
```

Preview and apply Agentera-owned lifecycle resources with the CLI:

```bash
npx -y agentera@next upgrade --runtime all --dry-run
npx -y agentera@next upgrade --runtime all --yes
```

Replace `all` with `opencode`, `codex`, `cursor`, or `copilot` to scope the
operation. Preview has no side effects. Apply never performs native package
installation, authentication, enablement, or trust approval.

Secure automatic apply is currently Linux-only. Other platforms receive the
same diagnosis and explicit `action_required` steps.

## Runtime package entry points

### OpenCode

```bash
npx -y agentera@next upgrade --runtime opencode --dry-run
npx -y agentera@next upgrade --runtime opencode --yes
```

This manages the one shared skill and previews the optional OpenCode plugin and
agent source. The OpenCode plugin does not install or repair skill links.

### Codex

Install the Agentera plugin from its marketplace entry, enable it in Codex, and
invoke `$agentera`. The package ships the Codex plugin manifest, plugin hooks,
copied-hook fallback, shared skill, and capability agent descriptors. Plugin
enablement and hook trust remain user-owned.

### Cursor

Cursor Agent CLI and Cursor IDE are surfaces of one `cursor` identity. CLI is
required; IDE is conditional. Lifecycle repair can install the canonical skill
and declared Agentera-owned IDE plugin, hook, and agent sources without making
the optional IDE a CLI support-floor requirement.

### GitHub Copilot

```bash
copilot plugin marketplace add jgabor/agentera
copilot plugin install jgabor/agentera
```

The package ships the Copilot plugin manifests and lifecycle hook files.

## Diagnose

```bash
npx -y agentera@next prime --format json
npx -y agentera@next doctor --format json
```

`prime` returns a bounded four-runtime summary. `doctor` reports detailed
evidence, support-floor gaps, ownership state, and exact host-native actions.

## Retired Claude data

Claude Code is not an active runtime. Its exact Agentera-owned legacy skill link
can be previewed separately with:

```bash
npx -y agentera@next upgrade --legacy-cleanup claude --dry-run
```

Historical transcript import is also explicit and excluded from default
analytics:

```bash
npx -y agentera@next report refresh --import-source claude
```
