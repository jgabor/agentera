---
title: Install and lifecycle
description: Run the Agentera CLI with its canonical shared skill and inspect project lifecycle state.
---

Agentera 3.0 uses one portable integration: the Agentera CLI plus one canonical
shared skill. The npm package ships no host-native plugin, hook, command, agent,
descriptor, or marketplace surface.

Before the stable npm dist-tag promotion, use `agentera@next`:

```bash
npx -y agentera@next prime
npx -y agentera@next doctor --format json
```

## Canonical skill

The canonical skill path is:

```text
~/.agents/skills/agentera
```

Normal upgrade previews or applies app/project migration with the CLI:

```bash
npx -y agentera@next upgrade --channel development --project "$PWD" --dry-run
npx -y agentera@next upgrade --channel development --project "$PWD" --yes
```

Preview has no side effects. Apply is the explicit, one-way v2-to-v3 migration;
it does not run a native package installer or create native runtime resources.

## Diagnose

```bash
npx -y agentera@next prime --format json
npx -y agentera@next doctor --format json
```

`prime` returns a bounded project brief. `doctor` reports read-only app,
project-state, shared-skill, and CLI evidence.

## Retired Claude data

Claude Code is not an active runtime. Its exact Agentera-owned legacy skill link
can be previewed separately with:

```bash
npx -y agentera@next upgrade --legacy-cleanup claude --dry-run
```

Historical transcript import is also explicit and excluded from default
analytics:

```bash
npx -y agentera@next report refresh --import-source claude
```

See the repository [upgrade guide](https://github.com/jgabor/agentera/blob/main/UPGRADE.md)
for ownership, recovery, and platform details.
